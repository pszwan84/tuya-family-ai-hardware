# 3 分钟路演脚本（Demo Day）

## 0:00–0:30 开场

> “你上一次和父母打电话，是什么时候？”

打开首页 `念念 · KinRing`，指出主标题：**各自生活，彼此看见**。
一句话定位：不是监控，是把各自的生活整理成彼此看得懂的故事。

## 0:30–1:10 相机与采集

- 展示挂件实物与外壳（3D 打印件）；
- 设备页：在线、采集中、存储余量；
- 按下“拍一张”或现场按键，指示灯亮起；
- 强调：相机只采集，不显示、不接收任何家人内容；可随时暂停。

## 1:10–1:50 一条素材变成事件

打开妈妈身份的“我的待分享”：
- 卡片包含画面、标题、发生了什么、为什么分享给你；
- 详情页五要素：人物 / 行为 / 对象 / 场景 / 时间；
- AI 标注可见，低置信度与风险项明确；
- 一句话：AI 只包装事实，不编造对白和情绪。

## 1:50–2:30 两种家人，两种说法

- 打开分享面板，默认零选中；
- 选择奶奶与孩子，预览两个版本：
  - 奶奶版更短、更直白；
  - 孩子版更口语；
- 强调事实一致，只是“怎么说”不同。

## 2:30–2:55 分享与撤回

- 确认分享，切换到奶奶身份：2 秒内看到自己的版本；
- 切回妈妈撤回：奶奶侧消失，妈妈个人时间线保留；
- 说明：撤回不是删除，删除也不会影响已生成的卡片。

## 2:55–3:00 收尾

> “远方有人念，家里有人盼。念念，把日常讲成家常。”

## 现场兜底

| 故障 | 处理 |
|---|---|
| 现场设备离线 | 用 `npm run mock:device -- happy` 重放，话术说明“同一链路的预置素材” |
| AI 超时 | 模板卡照常展示，说明“图像暂不可用，事实不变” |
| 网络断开 | 展示已生成事件与时间线，强调离线缓存与补传 |
| 账号切换失败 | 刷新页面重试；演示数据已 seed |
