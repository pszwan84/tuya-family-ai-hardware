# 演示脚本（≤8 分钟）

| 时间 | 步骤 | 操作 | 观察点 | 失败话术 |
|---|---|---|---|---|
| 0:00 | 1 | 打开 `/login`，以妈妈（mid01）进入 | 显示“我的待分享” | “演示身份切换失败，我们直接看已准备的数据” |
| 0:30 | 2 | 设备页展示在线/采集状态 | 三态与最近上传 | “设备当前离线，指令会在上线后生效” |
| 1:00 | 3 | 按键采集（或 `npm run mock:device -- happy`） | 灯亮 → 上传 → 待分享出现新事件 | “现场网络不稳，用预置照片重放同一链路” |
| 2:00 | 4 | 打开事件详情 | 五要素事实、AI 标注、来源素材仅本人可见 | “AI 不可用时展示文字卡，事实不变” |
| 3:00 | 5 | 打开发分享面板，选择奶奶 + 小满 | 默认零选中；切换接收人预览 | “未选接收人时不会允许提交” |
| 4:00 | 6 | 对比两个角色版本 | 标题/摘要/为什么给你不同，事实一致 | “版本由模板保底生成” |
| 5:00 | 7 | 确认分享 | 成功提示 + 写入审计 | “失败保留草稿，可重试” |
| 5:30 | 8 | 切换到奶奶（gp01） | 家庭视图 2 秒内出现对应版本 | “轮询间隔 1.5 秒，稍等即可” |
| 6:30 | 9 | 切回妈妈，撤回分享 | 奶奶侧 2 秒内消失，个人时间线保留 | “撤回与删除是两件事” |
| 7:00 | 10 | 展示设置页与设备暂停 | 暂停 10 秒内生效；提示只在 Web | “设备下行永不含家庭内容” |
| 7:30 | 11 | 收尾 | 强调素材与分享分离、AI 标注不可隐藏 | — |

## 演示前检查

```bash
npm run demo:reset
npm run demo:seed
npm run demo:verify
```

`demo:verify` 全绿才进入演示；事实核验未通过的事件不得进入演示。
