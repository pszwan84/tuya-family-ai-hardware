# ADR-001 现场对齐：ESP32-S3-CAM 与现有“一方小家”系统

- 日期：2026-11-06
- 状态：已采纳（用户授权自主决策，目标为次日 Demo Day）
- 影响范围：硬件、固件协议、演示路径、Web 首屏与叙事

## 背景

现场资料（`现场/`，已加入 `.gitignore`）显示：

1. 实物为 ESP32-S3-CAM N16R8 / Seeed XIAO ESP32S3 Sense，配 3D 打印挂件外壳与太阳能，**不是涂鸦 TuyaOS 开发板**。
2. 现场固件 `v1.1-sd-cmd`：VGA、画质 12、SD 卡缓存、每 10 秒轮询指令、远程拍照 / 暂停 / 定时间隔 / 立即补传 / 重启。
3. 已有线上系统 `http://111.229.200.105:18766/`，标题「一方小家 · 一起把日子养大」，浇花游戏化首页。
4. 产品叙事：念念 · KinRing / AI 亲情相机，主张「各自生活，彼此看见」，轻硬重软，3 分钟路演。
5. 参考资料：MiBee Cam、omiGlass、`Dalaoyuan2020/call-home`（当前不可匿名访问）。

## 决策

1. **硬件基线改为 ESP32-S3-CAM**；涂鸦固件保留为历史方案，不再作为演示路径。
2. **不改动现场在跑的固件与线上系统**，本仓库定位为「事件整理 + 双角色叙述 + 分享与家庭时间线」层。
3. 新增 **ESP32-S3 参考固件**（`firmware/esp32s3/`），协议与现场固件对齐：10 秒命令轮询、VGA、SD 队列、补传、暂停、定时间隔。
4. 新增 **外部素材导入**：把现场照片或已有系统素材导入本系统，用于演示与事件生成。
5. Web 首屏改为公开产品页（海报叙事），登录后进入 Me / Family。
6. 演示话术按 3 分钟路演重写，数据允许预置，但必须标注 AI 整理与降级状态。

## 影响

- 后端设备接口新增 `set_capture_params` / `resync` 命令类型与 Web 下发端点。
- 固件不再依赖 TuyaOS；G0 记录中与涂鸦相关的项改为 ESP32-S3 实测项。
- `docs/demo-script.md` 的 8 分钟脚本保留，另加 3 分钟路演版。

## 风险

| 风险 | 处置 |
|---|---|
| ESP32-S3-CAM 引脚随板型不同 | `firmware/esp32s3/src/config.h` 标注需按实物核对；未核对不得烧录 |
| 本机无 ESP32 工具链 | 固件仅提供源码与 PlatformIO 配置，编译需在装有 PlatformIO 的机器执行 |
| 现有系统不可改 | 通过导入脚本与命令兼容层衔接，不依赖其内部接口 |
| 现场网络不稳定 | 保留 inline 队列、模板卡、Mock 设备三套降级 |
| 现场资料含明文令牌 | 目录已 gitignore；令牌应在后台重新签发，禁止提交 |

## 未决

- 是否最终替换现有「一方小家」系统，Demo Day 后再评估。
- 设备端是否启用 HTTPS（G0-1 等价项）需在实物上实测。
- 是否公开仓库：待用户确认，现场令牌必须先行作废。
